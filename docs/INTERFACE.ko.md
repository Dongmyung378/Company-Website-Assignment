# UI와 주요 사용 흐름

[프로젝트 소개](../README.ko.md)

실제 화면을 표시하는 PHP 페이지 17개에 공통 UI를 적용했습니다. `index.php`는 기존처럼 로그인 화면으로 연결합니다. 별도 프런트엔드 빌드 없이 로컬 CSS와 JavaScript, SVG를 사용하며 외부 글꼴이나 CDN을 요청하지 않습니다. 기존 주소, 데이터와 보안 검사 및 과제의 급여 계산 규칙은 유지합니다.

## 개선한 내용

| 영역 | 사용자가 확인할 변화 |
| --- | --- |
| 메뉴 | PC의 고정 메뉴와 현재 위치 표시, 본문 바로가기, 모바일 메뉴와 Escape 닫기 및 키보드 초점 복원 |
| 관리자 홈 | 실제 직원 수, 대기 신청, 당일 휴가와 사무실 수를 요약하고 팝업 대신 화면 안에 승인 안내 표시 |
| 직원 홈 | 자신의 잔여 휴가, 최근 처리 내역과 개인 업무 바로가기 |
| 직원 목록 | 이름과 이메일 검색, 펼칠 수 있는 상세 필터, 이름순 정렬, 필터를 유지하는 12명 단위 페이지 이동 |
| 직원 프로필 | 업무 및 연락처, 개인 정보와 비상 연락처를 구분하고 해당 직원의 수정 화면으로 바로 연결 |
| 직원 입력 | 필수 항목과 입력 조건 안내, 선택한 부서에 속하는 직책 표시, 날짜 제한과 오류 안내 |
| 휴가 | 시작일과 종료일을 포함한 달력 일수, 승인 후 예상 잔여량, 상태 배지와 신청 내역 |
| 보고서 | 명확한 필터, 요약 카드와 표의 내부 스크롤, 기존 급여 계산식과 CSV 유지 |
| 비밀번호 | 표시 전환과 새 비밀번호 일치 확인, 현재 비밀번호 및 최초 변경 의무 유지 |
| 제출 | 삭제 등 주요 작업의 확인 절차, 클릭한 작업명을 유지하는 중복 제출 방지 |

검색어의 `%`, `_`, `!`는 SQL 매개변수로 전달하고 일반 문자로 검색합니다. 유효하지만 큰 페이지 번호는 마지막 페이지로 이동하고, 잘못된 값과 배열형 입력 또는 범위를 벗어난 값은 거부합니다. 상세 필터를 적용한 경우 필터 영역이 자동으로 펼쳐집니다.

부서별 직책 표시와 휴가 미리보기는 입력을 돕는 기능입니다. 서버는 별도로 소속 관계, 계정 상태, 날짜와 잔여량, CSRF, 변경 버전과 트랜잭션을 검사합니다. JavaScript 없이도 서버 화면과 검증은 유지합니다. 넓은 표는 화면 전체가 아닌 패널 안에서 스크롤하며 모션 최소화 설정과 인쇄 화면도 지원합니다.

## 로컬 로그인

기존 [설정 가이드](../database/README.ko.md)를 따릅니다. 로그인 정보는 비공개 로컬 파일로 제공하며 소스에 고정된 공개 비밀번호를 넣지 않습니다. 소유자의 로컬 데모 계정과 로그인 안내는 Git에서 제외한 실행 데이터입니다. 임시 비밀번호는 처음 로그인할 때 변경해야 합니다.

## 실행 및 화면 검증

초기 보안 수정 기록은 유지하고 최신 결과를 별도 파일로 기록합니다.

현재 기록은 **HTTP 및 업무 검증 97/97 통과**, **실제 브라우저 검사 219/219 통과**, **화면과 크기 조합 41개 및 스크린샷 12개 확인**, **PHP 문법 47개 파일 모두 통과**입니다. 모든 화면은 PC 1440px과 모바일 390px에서 확인했으며 360px 및 768px도 보충 검사했습니다.

- [HTTP 및 업무 회귀 검증](verification/ui-regression.json): 기존 83개 검사에 검색, 출력 이스케이프, 페이지 이동, 직원 수정 바로가기 및 관리자 제한 검사 14개를 추가했습니다.
- [PHP 문법 검사](verification/ui-php-lint.json): 공통 UI를 포함한 실행 소스 47개 파일을 확인했습니다.
- [실제 브라우저 검증](verification/ui-browser.json): 1440px PC와 390px 모바일에서 모든 화면을 확인하고 360px 및 768px도 보충 검사합니다. 화면 구조, 중복 ID와 입력 이름표, 전체 화면의 가로 넘침, 스크립트와 자원 오류, 메뉴, 휴가 미리보기 및 CSRF를 포함한 실제 버튼 제출을 확인합니다.

폐기 가능한 `_test` 데이터베이스에서 실행합니다.

~~~sh
python tests/security_regression.py
~~~

선택 브라우저 검증에는 로컬 Microsoft Edge와 Python의 `websocket-client` 패키지가 추가로 필요합니다. 별도 브라우저 프로필과 테스트 계정을 사용하고 자체 서버 및 브라우저를 종료합니다.

~~~sh
python tests/browser_ui.py
~~~

Edge 설치 경로가 다르면 `--edge /path/to/msedge` 또는 `EDGE_BIN`으로 지정합니다. 두 스크립트 모두 `PHP_BIN`과 `PHP_ARGS_JSON`을 사용합니다. [검증 설정](SECURITY.ko.md)을 함께 참고하세요. 스크린샷은 Git에서 제외한 `var/ui-screenshots/`에만 저장하며 인증정보나 브라우저 프로필을 공개하지 않습니다.

화면 크기별 자동 검사와 시각 검토는 로컬 Edge의 해당 크기를 대상으로 했습니다. 접근성 인증이나 모든 브라우저 및 모든 길이의 내용에 대한 호환성을 보장하는 검증은 아닙니다. 기존 기능은 화면과 별도로 HTTP 및 동시 요청 검증도 수행합니다.
